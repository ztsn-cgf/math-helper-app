# 调研笔记 — 权威资料与关键结论

> 生成时间：2026-10-01
> 用途：记录「小学数学错题辅助工具」地基数据的权威来源与教材版本决策依据。

## 1. 教材版本（重要决策点）

北师大版三年级数学存在**两套版本**，知识点树的单元编排需据此确定：

### A. 2012 传统版（仍广泛使用，DESIGN.md 采用的就是这套）

**三年级上册**（8 单元 + 数学好玩 + 总复习）：
混合运算 → 观察物体 → 加与减 → 乘与除 → 周长 → 乘法 → 年、月、日 → 认识小数

**三年级下册**（7 单元 + 整理与复习 + 数学好玩 + 总复习）：
除法 → 图形的运动 → 乘法 → 千克、克、吨 → 面积 → 认识分数 → 数据的整理和表示

### B. 2024 新教材版（新课标 2022 修订，正在逐年铺开）

- 上册调整为含「测量（二）」「调查与记录」等新单元；下册含「整数乘法（一）」「图形的运动（二）」「周长」等，单元名与顺序与传统版差异较大。
- 铺开节奏大致为：2024 秋一年级 → 逐年跟进。**2026 秋三年级大概率已用新教材**，但需以孩子实际课本为准。

> 结论：本仓库知识点树先按「领域（版本无关）」组织，教材单元序号待确认版本后再补映射。详见 `data/knowledge-points.json`。

## 2. 课标依据（量感 / 空间观念）

- 《义务教育数学课程标准（2022 年版）》首次把**「量感」**单独列为核心素养表现，是 2022 版相对 2011 版**唯一新增**的核心素养内容。
- **量感定义**：对事物可测量属性及大小关系的直观感知（长短、轻重、大小、方圆等）。
- **空间观念**：对图形及图形关系的感知，本产品对应「三视图 / 轴对称 / 平移旋转 / 展开图折叠」。
- 长度单位是培养量感的**起始与关键载体**；典型教学痛点：学生能填「铅笔长( )厘米」，却估不准「教室门高几米」——即量感未真正建立。

## 3. 量感建立的三个层次（用于讲解/出题设计）

1. **统一**：经历统一度量单位的过程，理解统一单位的意义。
2. **选择**：会选合适的单位并做单位换算。
3. **估计**：用参照物合理估测（先估后量）。
